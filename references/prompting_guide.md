# Kimi Prompting Guide

## Best Practices

### Be Specific
- Include file paths when relevant
- Mention specific technologies
- Define expected behavior

### Provide Context
- Link to related files
- Reference existing patterns
- Include error messages

### Set Boundaries
- Define what's in scope
- Mention constraints
- Specify what NOT to change

## Example Prompts

### Building
"Build a React component for [X].
Use TypeScript, Tailwind CSS.
Include error handling and loading states.
Write unit tests with Jest."

### Refactoring
"Refactor [file] to use [pattern].
Maintain backward compatibility.
Update all imports and usages.
Keep tests passing."

### Debugging
"Fix [error] in [file].
The error occurs when [condition].
Check [related files] for context."
